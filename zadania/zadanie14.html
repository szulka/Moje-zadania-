Zadanie 1. Moje kieszonkowe (łatwe)

Napisz program w języku C++, który pobierze od użytkownika informacje dotyczące jego kieszonkowego[cite: 1].

Kod programu (C++):

#include <iostream>

using namespace std;

float kieszonkowe;

int main() {
    int wiek;

    cout << "Ile masz lat? ";
    cin >> wiek;

    cout << "Ile kieszonkowego otrzymujesz miesiecznie? ";
    cin >> kieszonkowe;

    cout << "\nTwój wiek: " << wiek << " lat" << endl;
    cout << "Twoje kieszonkowe: " << kieszonkowe << " zl" << endl;

    return 0;
}
